# Склад «Дело в коробке»

Складская система фулфилмента: приёмка, размещение, сборка по маршруту, инвентаризация, остатки, справочник товаров со штрихкодами, ячейки с этикетками, журнал операций, сотрудники с ролями.

Работает в браузере на телефоне, ТСД и компьютере. Можно добавить на главный экран телефона как приложение. Сканирование: ручной сканер (Bluetooth / USB) или камера телефона.

## Запуск на Amvera (российский хостинг)

1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru) и пополните баланс (тариф «Начальный» или выше).
2. **Создать проект** → тип «Приложение» → название, например `sklad` → тариф.
3. Способ загрузки: **через GitHub** (выберите этот репозиторий) или **через интерфейс** (загрузите все файлы репозитория).
4. Конфигурация подхватится из файла `amvera.yml`: Docker, порт 8080, постоянное хранилище `/data`.
5. Дождитесь сборки (статус «Приложение запущено»).
6. В разделе **Домены** включите бесплатный домен вида `sklad-ИМЯ.amvera.io` с HTTPS. Можно привязать свой домен, например `sklad.delovkorobke.ru`.
7. Откройте адрес. Первый, кто откроет, создаёт администратора, поэтому сделайте это сразу.

> Все данные хранятся в файле `/data/sklad.db` на постоянном диске Amvera. Обновления приложения их не затрагивают.

## Первые шаги

1. **Управление → Новый сотрудник**: заведите логины кладовщикам.
2. **Остатки → Загрузить раскладку**: перенесите текущие остатки из Excel (столбцы: Ячейка, Клиент, Артикул, Наименование, Количество, Штрихкод).
3. **Ячейки → Создать**: сгенерируйте адреса и напечатайте этикетки.
4. **Товары → Загрузить из Excel**: загрузите штрихкоды товаров (или они привяжутся сами при приёмке).

## Услуги и счета

- **Приёмка и сборка** начисляются сами: одна строка на каждую поставку и каждую сборку, по количеству штук.
- **Хранение** считается при выставлении счёта: остаток клиента на конец каждых суток (по московскому времени) × цена за шт·сутки. Уже выставленные сутки второй раз не попадают.
- **Остальные услуги** (упаковка, маркировка, доставка, свои) кладовщик добавляет во вкладке **Услуги**.
- **Счета** (администратор): тарифы по умолчанию, отдельные цены для клиента, реквизиты, выставление счёта за период с предпросмотром, печать или PDF, отметка «оплачен», отмена (услуги из отменённого счёта снова можно выставить). Сверху видно, сколько услуг ещё не выставлено клиентам.
- Клиент видит в кабинете свои счета и услуги, которые ещё не вошли в счёт.

Стартовые цены в тарифах примерные: поменяйте их на свои в **Счета → Тарифы** и заполните **Реквизиты**.

## Личный кабинет клиента

Селлер входит по своему логину на тот же адрес и видит только свои товары:

- **Остатки**: сколько каждого артикула на складе и сколько ещё в приёмке (не разложено), выгрузка в Excel;
- **Поставки**: все принятые поставки с актом приёмки и расхождениями;
- **Движение товара**: поступления, отгрузки, инвентаризации и корректировки, выгрузка в Excel;
- **Пароль**: клиент может сменить пароль сам.

Данные обновляются сами, без перезагрузки страницы.

Как дать доступ: **Управление → Новый пользователь** → роль «Клиент» → в поле «Клиент (компания)» выберите компанию из списка. Название должно совпадать с тем, как клиент записан в остатках (регистр и лишние пробелы не важны). Перед выдачей доступа можно посмотреть кабинет глазами клиента: **Управление → Кабинет клиента → Открыть кабинет**.

## На телефоне

- **Android (Chrome):** меню ⋮ → «Добавить на главный экран».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
- Камера сканирует штрихкоды только по адресу `https://`.

## Резервные копии

Сервер раз в сутки сохраняет копию базы в `/data/backups` и хранит последние 14. Скачать копию вручную: **Управление → Скачать базу**.

## Обновление

Новая версия кода в GitHub → Amvera пересобирает приложение (или нажмите «Пересобрать» в проекте). Данные сохраняются.

## Свой сервер (VPS)

```bash
git clone <адрес репозитория> sklad && cd sklad
docker compose up -d
```

Приложение будет на порту 8080, данные в папке `./data`. Для камеры нужен HTTPS (Caddy или nginx с сертификатом).

## Разработка

Нужен Node.js 22.13 или новее. Внешних зависимостей нет.

```bash
npm start   # http://localhost:8080, данные в ./data
npm test    # автотесты сервера
```

Переменные окружения: `PORT` (8080), `DATA_DIR` (`/data` или `./data`), `ADMIN_LOGIN` и `ADMIN_PASSWORD` (создать администратора при первом запуске без экрана настройки), `TZ_OFFSET_HOURS` (часовой пояс для суток в учёте услуг, по умолчанию 3 — Москва).
